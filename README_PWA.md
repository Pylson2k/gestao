# 📱 Guia de Instalação do PWA — SINAI ENGENHARIA

## Como Instalar no Celular

### Android (Chrome)

1. Abra o Chrome no seu celular Android
2. Acesse o site do SINAI ENGENHARIA
3. Você verá um banner na parte inferior da tela oferecendo para instalar o app
4. Toque em **"Instalar"** ou **"Adicionar à tela inicial"**
5. Ou acesse o menu do Chrome (três pontos) → **"Adicionar à tela inicial"**

### iOS (Safari)

1. Abra o Safari no seu iPhone/iPad
2. Acesse o site do SINAI ENGENHARIA
3. Toque no botão de compartilhar (quadrado com seta para cima)
4. Role para baixo e toque em **"Adicionar à Tela de Início"**
5. Personalize o nome se desejar e toque em **"Adicionar"**

## Funcionalidades do PWA

✅ **Funcionamento Offline**: O app funciona mesmo sem internet (com limitações)
✅ **Acesso Rápido**: Ícone na tela inicial como um app nativo
✅ **Experiência Nativa**: Sem barra de navegação do navegador
✅ **Atualizações Automáticas**: O app se atualiza automaticamente
✅ **Otimizado para Mobile**: Interface totalmente adaptada para celular

## Requisitos

- **Android**: Chrome 67+ ou outro navegador compatível
- **iOS**: Safari 11.1+ (iOS 11.3+)
- Conexão com internet na primeira instalação

## Atalhos Rápidos

Após instalar, você pode usar atalhos:
- **Novo Orçamento**: Acesso direto para criar orçamento
- **Adicionar Despesa**: Acesso direto para registrar despesa
- **Dashboard**: Voltar para a tela inicial

## Suporte

Se tiver problemas com a instalação:
1. Certifique-se de estar usando um navegador compatível
2. Verifique se o site está acessível
3. Tente limpar o cache do navegador
4. Reinicie o navegador
